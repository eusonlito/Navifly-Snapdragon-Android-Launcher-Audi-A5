THEME 3 — "Telemetría" (motorsport data tiles, high contrast).
Split layout: the map is a large rounded rectangle on the left ~58% of the screen (dark-mode vector map, neon road highlights). The right side is a modular grid of square-cornered data tiles like a race-engineering pit-wall screen: one big tile with speed as huge monospace digits; a tile with RPM as a horizontal shift-light LED strip (green → yellow → red) plus the gear in a large box; small tiles for consumption (with a tiny sparkline), range, trip time, trip km, partial km, odometer; a fuel tile with stacked segmented blocks. Witnesses as a car top-view outline tile with door segments and three status pips. Commands as a vertical icon rail on the far left edge. Palette: carbon black, white monospace numerals, signal yellow (#FACC15) accent, green/red only for status. Technical grid lines, tight alignment.
