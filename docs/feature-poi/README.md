# Puntos de Interés

A5 Cockpit permite añadir puntos al mapa sin incluir catálogos de terceros en el
APK. Cada fuente es un fichero GeoJSON estándar, `categories.json` concentra la
presentación de cada categoría y cada icono opcional es un PNG. La aplicación
combina todos los ficheros importados y los conserva en su almacenamiento
privado.

- [Formato y gestión](POI.md)
- [Conversores](CONVERTERS.md)

No se descarga ninguna fuente automáticamente. El usuario controla qué datos
importa, cuándo los actualiza y qué licencia permite su uso.
